# LoomLoom Context Routing

Use the smallest relevant set.

| Task class | Required LoomLoom context | Usually exclude |
|---|---|---|
| Disposable sketch / exploration | intent + R0 rules | high-assurance policy, runtime research |
| Normal retained feature | canon + relevant contract + R1 | unrelated experiments, Archive |
| Controlled/high-risk correction | relevant canon/contracts + authority + R2/R3 evidence policy | unrelated research |
| Benchmark / blinded experiment | relevant contract + evaluation policy + topology rules | product-runtime material not used by experiment |
| Runtime integration | canon + current accepted decisions + relevant runtime research/experiment | unrelated project research |
| Browser extension development | normal task context + relevant accepted decisions + browser extension profile | unrelated runtime/store material unless material |
| Evolve LoomLoom itself | Status & Decisions + canonical baseline + relevant accepted decisions + bounded research | Archive unless historical reasoning needed |
| Explain why a past direction was rejected | current decision + selected Archive/reconciliation | unrelated active experiments |

## Materiality test

A source is material when changing or removing it could alter one of:

- task interpretation;
- contract/acceptance conditions;
- authority;
- exact subject/candidate identity;
- required evidence;
- execution topology/rigor;
- promotion decision;
- reproduction of the result.

If not material, do not load it by default.
