# Changelog

Public distribution changes are recorded here. Internal research/proposal iterations are intentionally not mapped one-to-one to public release versions.

## v0.3.0-alpha.1 — release candidate

First intended public LoomLoom distribution.

Includes:

- Development Kernel v0.1 public specification projection;
- accepted Bootstrap v0.1 distribution;
- Agent Skill bootstrap path;
- exact project pinning and portable package identity;
- Agent Operating Behavior v0.1 projection;
- Browser Extension Development Profile v0.1 projection;
- public authority closure: released tag/repository contents are self-contained for consumers;
- public quickstart and release/versioning metadata.

Known maturity limits:

- open alpha; no 1.0 compatibility promise;
- generic Kernel lifecycle is not implemented end-to-end as one executable platform;
- cross-runtime support beyond the currently dogfooded runtime family is not yet validated;
- later accepted Continuity and policy/profile revisions are not included by implication.

## Unpublished internal generations

The project had earlier internal semantic generations corresponding approximately to 0.1 and 0.2. They were development lineage, not public releases, and receive no retrospective tags.
